🐍 PYQUEST – Learn Python. Level Up.

A gamified Python learning web application designed to make learning programming fun, interactive, and motivating. 🚀

✨ Features:
🎮 Gamified Python learning experience
🗺️ Level and world-based learning journey
📝 Python skill assessment
🎯 Personalized starting level recommendations
📚 Python concepts and coding challenges
🏆 Progress tracking
🔥 Daily streak motivation
🎓 Achievement and milestone certificates
🌍 Interactive learning worlds
💾 User progress stored using SQLite


🛠️ Tech Stack:
Python
Flask
SQLite
HTML
CSS
JavaScript

🚀 How to Run the Project..? :
1. Clone the repository.
2.Install Flask:
pip install flask
3. Run the application:
python app.py
4. Open your browser and visit:
http://127.0.0.1:5000/


🎯 Project Goal
PyQuest aims to make Python learning feel like a game by combining programming concepts, coding challenges, progress tracking, and an engaging level-based journey.
